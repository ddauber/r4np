# Halloween

A dataset which contains data about Halloween consumer behaviour across
the US, the UK and Germany.

## Usage

``` r
halloween
```

## Format

A data frame with 5982 rows and 3 variables:

- expenses:

  Expenses related to Halloween candies

- distance:

  Distance covered while 'Trick-or-treating'

- country:

  Participants country of residence
