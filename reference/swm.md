# Salary, Work experience, and Mindfulness (SWM)

This dataset contains information about employees' salary, their working
experience and time spend on mindfulness practices.

## Usage

``` r
swm
```

## Format

A data frame with 100 rows and 3 variables:

- salary:

  Salary earned (in USD 1000)

- work_experience:

  Years of working experience

- mindfulness:

  Minutes spent on mindfulness practices in a 5-day working week.

## Source

Fictitious dataset created for educational purposes.
