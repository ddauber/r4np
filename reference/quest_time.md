# Start and end dates/times of a questionnaire

A dataset which contains start and end dates regarding the completion of
a questionnaire.

## Usage

``` r
quest_time
```

## Format

A data frame with 84 rows and 3 variables:

- id:

  Unique identifier of participant

- start:

  The date and time at which a participant started the questionnaire

- end:

  The date and time at which a participant finished the questionnaire

## Source

A random selection of observations from the Global Education Profiler
(GEP).
